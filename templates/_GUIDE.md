# {폴더명}/ — 폴더 가이드

> ⚠️ **이 문서는 설명서가 아니다.** "이 폴더에서 하면 안 되는 것"과 "반드시 이렇게 해야 하는 것"만 적는다.
> 코드가 하는 일은 코드를 읽으면 된다. 여기 적을 것은 **코드를 읽어도 모르는 것** — 왜 이렇게 됐는지.

## 역할

(2~4줄. 이 폴더가 소유한 책임과 소유하지 않은 책임.)

**이 폴더가 소유하지 않는 것**: (경계를 먼저 적는다. 월권이 대부분의 사고 원인이다.)

## 핵심 패턴

## 금지사항

> 각 항목에 **사고 이력**을 붙인다. 없으면 규칙이 아니라 취향이다.

### ❌ {금지할 행위}
```python
# ❌ 금지
...

# ✅ 대신
...
```
**사고 이력**: (언제, 무엇이 깨졌는지. 한두 줄.)

---

## GC 패턴

> 위 금지사항 중 **정규식으로 잡히는 것**을 여기 적는다. harness --gc 가 이 블록을 파싱해
> 폴더 내 소스에 적용한다. 규칙을 문장으로만 두면 안 지켜진다.

```gc
pattern: "except\s+Exception:\s*(pass|continue)"
message: "silent failure 금지 — 반드시 로깅 후 처리"
```

## 하네스

> harness 가 이 블록을 읽어 테스트를 라우팅한다. 즉 **이 문서가 테스트 매니페스트**다.

```
tests:
  - tests/unit/test_{폴더}.py
  - tests/invariants/test_{불변식}.py
```

```bash
python scripts/harness.py {폴더}/
```
