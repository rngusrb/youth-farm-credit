## 팀원 C

### 좋았던 점
- 전체적인 서비스 흐름이나 기능 구성은 잘 잡혀 있는 것 같음
- 농가용/금융기관용 화면이 나눠져 있어서 각자 필요한 정보를 볼 수 있는 점 좋음
- 단순 대출한도만 보여주는 게 아니라 소득, 상환여력, 스트레스 상황까지 같이 보는 점 좋음
- 숫자를 AI가 임의로 만드는 게 아니라 별도 계산 로직으로 산출하게 한 것도 신뢰성 측면에서 좋은 것 같음
- 데이터 출처나 계산 근거도 어느 정도 갖춰져 있어서 이 부분 잘 살리면 좋을 듯

### 피드백 사항
- 전체적으로 글자가 조금 딱딱함 → 농가가 보는 화면은 전문용어보다 좀 더 쉽게 풀어서 쓰면 좋을 듯
- 정보가 한 번에 너무 많이 보이는 느낌 있음 → 결론 → 이유 → 상세정보 순으로 필요한 정보만 단계적으로 보여주면 좋을 것 같음
- 특히 정보가 단순 나열되는 것보다는 내 농가 조건에 맞는 정보만 필터링해서 보여주는 느낌이 더 나면 좋겠음
- DSCR, 스트레스 테스트 같은 용어는 농가 화면에서는 `상환여력 안정적`, `가격 하락 시 주의`처럼 의미 위주로 바꿔도 좋을 듯
- 대출도 최대한도만 보여주기보다 실제로 무리 없이 빌릴 수 있는 금액을 먼저 보여주면 좋을 것 같음
- 정확한 산식이랑 데이터 출처는 필요할 것 같음. 대신 화면에 전부 노출하기보다는 계산 근거 보기처럼 필요할 때 확인할 수 있게 하면 좋을 듯
- 전체적으로 금융 계산기보다는 내 농가 상황을 보고 필요한 정보랑 다음 행동을 알려주는 서비스 느낌이 조금 더 나면 좋겠음

### 추가하면 좋을 점
- **왜 이런 결과가 나왔는지 확인할 수 있는 기능** 있으면 좋을 듯 → 계산 근거/산식/사용 데이터 출처 정도
- **정보 기준 시점**도 있으면 좋을 것 같음 → 농산물 가격이나 정책자금 같은 건 계속 바뀌니까 `2026.08 기준`처럼 표시
- **추천 이유**가 같이 나오면 좋겠음 → 그냥 정책자금 추천보다는 `청년농 + 재배면적 + 경영기간 조건에 해당해서 추천` 이런 식
- 반대로 **왜 제외됐는지도** 간단하게 보여주면 좋을 듯 → 정보 필터링한다는 느낌이 더 잘 날 것 같음
- 현재 상태만 보여주기보다는 **앞으로 뭘 하면 되는지** 액션까지 연결되면 좋을 듯 → `상환계획 조정하기`, `지원 가능한 정책 확인하기` 등
- **시나리오 비교**도 있으면 좋을 것 같음 → 대출 5천/7천/1억일 때 또는 가격이 10%, 20% 떨어졌을 때 어떻게 달라지는지
- 농가가 계속 사용하는 서비스로 보이려면 **지난 분석 대비 어떻게 변했는지**도 있으면 좋을 듯 → 소득 전망 ↑, 상환부담 ↓ 이런 식
- 마지막으로 금융기관 화면에는 **농가가 입력한 값 / 공공데이터에서 가져온 값 / AI가 추정한 값**을 구분해서 보여주면 신뢰도 측면에서 좋을 것 같음
