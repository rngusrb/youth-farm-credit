## 태스크별 결과

### UX-009: 정보 기준 시점이 어디에도 없다
- **완료 기준 달성**: ✅
- **한 일**: 엔진이 `as_of` 를 내려주고(`income_survey_year`·`cost_survey_year`·
  `sigma_series`·`market_window`·`guideline_year`/`checked_on`), 리포트 표지·농가 홈·
  작목 데이터·시세·자료실이 그대로 표시한다. `<AsOfLine>` / `asOfParts()`.
- **핵심 결정 1 — 조사연도가 섞여 있다는 사실을 드러냈다.**
  상단 라벨이 "농촌진흥청 2023년 농산물 소득조사" 였는데, 실제로는 원래 6작목만 2023년이고
  나중에 늘린 32작목은 2024년이다. **32작목에 대해 라벨이 틀려 있었다.**
  라벨에서 연도를 빼고(`작목마다 조사연도가 다르다`) 작목 표의 소득 옆에 각각 적었다.
  6작목의 `income_year: 2023` 은 최초 커밋(`1e58ded`)의 `source` 줄이 근거다.
- **핵심 결정 2 — 지침 연도 두 개를 분리했다.**
  자료실에 색인된 원문은 **2026년판 3종**이고, 대출조건(거치·상환·재해연기)을 쪽·인용까지
  대조한 문서는 **2025년판**이다. "지침 확인" 한 마디로 묶으면 둘이 같은 것처럼 읽혀서
  `대출조건 2025년 지침 대조 2026-08-25` 로 적는다.
- **핵심 결정 3 — 없는 날짜는 채우지 않는다.** `_as_of()` 는 값이 없는 키를 아예 뺀다.
  화면의 `new Date()` 는 리포트 **발행일**에만 남기고 그 옆에 기준 시점을 붙였다 —
  발행일만 있으면 읽는 사람이 숫자도 오늘 것이라 읽는다.
- **재현 명령어**:
  ```
  cd apps/api && python -m pytest tests/test_as_of.py -q
  cd apps/web && npx vitest run --root . tests/asof.test.ts
  curl -s localhost:8000/api/v1/crops | python3 -c "import json,sys;d=json.load(sys.stdin);print(d['source'])"
  ```

### UX-001: 정보량 — 결론 먼저, 근거는 접기
- **완료 기준 달성**: ✅ (인쇄 항목은 범위에서 제외 — 아래)
- **한 일**: `<Fold>` 공용 컴포넌트. 리포트 04장(요인분해)·06장(계산 전제), 안전진단의
  가정·한계에 적용. 리포트 내용 총량 **304 → 267단위**.
- **핵심 결정 — 지우지 않고 접는다.** 세 팀원 모두 "정보량이 많다"고 했지만 세 명 모두
  "근거가 설득력 있다"고도 했다. 지우면 후자를 잃는다. 접힌 내용은 DOM 에 남는다.
- **핵심 결정 — `<details>` 를 쓴다.** 키보드·스크린리더 동작이 브라우저에 이미 있다.
  손으로 만든 토글은 그걸 매번 다시 틀린다.
- **범위에서 뺀 것**: "인쇄 시 펼침". 유저가 "인쇄는 고려하지 말라"고 명시했다.
  되살릴 때는 브라우저에서 실제로 확인할 것 — `content-visibility` 때문에 CSS 한 줄로는
  안 펼쳐진다.
- **재현 명령어**: `cd apps/web && npx vitest run --root . tests/fold.test.tsx`

### UX-010: 금융기관 화면에 값의 출처를 구분해 표시
- **완료 기준 달성**: ✅
- **한 일**: `<SourceTag>` (입력/통계/가정) + `<SourceLegend>`. 심사 대시보드·상환능력
  분석·적정 여신 설계에 적용. 여신 설계에 「이 설계가 선 가정」 3건(농가 고유변동성·
  재해확률·농신보 보증료)과 각각의 근거 또는 **근거 없음**을 적었다.
- **핵심 결정 — PARTIAL 을 "통계" 라고 부르지 않는다.** `sigmaSourceKind()` 는
  PARTIAL 을 `assumed` 로 옮긴다. 실측한 것은 시장 공통분뿐이고 딸기는 분산의 63%가
  가정이다. "통계" 로 부르면 심사역이 가정값을 실측으로 읽는다.
- **핵심 결정 — 배지는 라벨 칸에.** 심사 화면은 표가 주다. 숫자를 가리지 않는다.
- **재현 명령어**: `python3 scripts/harness.py apps/web`
