# SPRINT 2026-08-28 — 농가가 읽기 쉽게

## 목표

C 팀원 피드백 15건을 **코드로 대조**한 결과 6건 반영 · 4건 부분 · 5건 미반영이었다.
반영된 6건은 전부 **신뢰성** 쪽(출처·기준 시점·근거) — 팀원이 이미 좋다고 한 부분을
더 단단하게 만든 것이다. 정작 **고쳐달라고 한 쪽**(피드백 7개 중 앞 4개가 전부
"농가가 읽기 쉽게")은 말투만 바꾸고 용어·정보량·필터링은 그대로였다.

이번 스프린트는 그 넷을 잡는다.

## 태스크별 결과

### UX-011: 농가 화면 — 쉬운 말이 앞, 용어는 뒤
- **완료 기준 달성**: ✅ (5/5)
- **핵심 결정 — 팀원 의견을 그대로 따르지 않았다.**
  "DSCR 을 `상환여력 안정적` 으로 바꾸라" 는 확정 화법 규칙 4 와 정면 충돌한다:
  *"용어를 지우지는 않는다 — 농가가 은행에서 같은 말을 써야 한다."* 이 규칙은 유저가
  시안을 대목별로 고른 결과에서 뽑은 것이라 의견 한 줄로 뒤집지 않는다.
  지우는 대신 **순서를 바꿨다** — 뜻이 앞, 용어는 괄호·보조줄로 뒤.

  | 전 | 후 |
  |---|---|
  | `소득 변동성 σ 0.215` | `보통 해에 얼마쯤 · 4,318만원~7,489만원` / `10년 중 8년이 이 사이 (소득 변동성 σ 0.215)` |
  | `영업레버리지 2.46배` | `수입이 줄면 소득은 몇 배로 줄까 · 2.46배` |
  | `DSCR 1.25 기준` | `버는 돈이 갚을 돈의 1.25배 (DSCR 1.25)` |
  | `AI 권장 차입` | `소득 변동까지 반영` (규칙 2 — 처음 쓴 "무리 없는 금액" 은 우리 판정이라 뺐다) |
  | 메뉴 `스트레스 테스트` | `값이 떨어지면 어떻게 되나` |

- **핵심 결정 — 화면이 σ 를 ±% 로 환산하지 않는다.** 엔진에 `income.band_p10_p90`
  을 넣었다. `simulate.draw_paths` 와 **같은 분포**(`exp(σ·Z − σ²/2)`)를 쓰고,
  40만 회 추출 분위수와 대조해 오차 0.005%·0.035% 를 확인했다.
- **재현**: `cd apps/api && python3 -m pytest tests/test_income_band.py -q`

### UX-012: 내 조건 기준으로 걸러 보여주기
- **완료 기준 달성**: ✅ (5/5)
- **설계 수정** — 처음엔 「구제제도 화면」에 붙이려 했는데 자리가 틀렸다. 구제제도의
  해당 여부는 **피해율 30% 이상** 같은 미래 사건이라 지금 판정할 대상이 아니다.
  팀원이 말한 "추천 이유 / 제외 이유" 는 **정책자금 자격**이고, 코퍼스에 조문 단위로
  실측 확인된다.
- **핵심 결정 — 판정하지 않고 의견을 낸다.** 직전 스프린트에서 "자격을 잘못 판정하면
  받을 수 있는 사람이 포기한다" 는 이유로 통째로 뺐던 것을, 유저 의견대로 의견
  수준으로 되살렸다. 경계:

  | 한다 | 하지 않는다 |
  |---|---|
  | "Ⅱ-1-가 기준으로는 해당하지 않을 수 있어요" | "자격 없음" · "신청 불가" |
  | 근거 조항 원문 병기 | 조항 없이 결론만 |
  | 안 답한 요건엔 아무 말 안 함 | 빈 값을 0 으로 읽고 판정 |
  | 조문 못 찾으면 요건 자체를 안 보여줌 | 없는 근거로 추측 |

- **핵심 결정 — 요건 문장을 코드에 적지 않는다.** 구조(문서·조항번호·판정방식)만
  `loan_products.json` 에 두고 문장은 코퍼스 원문에서 끌어온다 (`rag/eligibility.py`).
- **재현**: `curl -s localhost:8000/api/v1/eligibility` ·
  `python3 -m pytest apps/api/tests/test_eligibility.py -q`

### UX-013: 농가 화면에 금액별 비교
- **완료 기준 달성**: ✅ (4/4)
- **한 일**: 엔진이 낸 세 기준에 농가가 직접 넣은 금액을 더해 나란히.

## 미완성 / 후속 (→ BACKLOG.md)

- **말투 혼용을 기계로 못 잡는다.** 농가 영역에 합니다체가 섞이는 일이 두 스프린트
  연속 사람 눈을 통과했다. 조사는 테스트로 막았지만 말투는 규칙 6·9 의 **정당한
  예외**가 많아 단순 grep 이 못 쓴다.
- **`ui_check` 가 로그인 뒤 화면을 스스로 검사하지 못한다.** 지금은 별도 스크립트로
  `localStorage` 를 심어야 한다 — 하네스에 안 들어간 검사는 결국 안 도는 검사다.
- 팀원 피드백 중 여전히 미반영: **지난 분석 대비 변화**(「내 리포트」가 목록만 보여주고
  비교하지 않는다), **추천 이유**(상품이 둘뿐이고 "왜 이게 맞는지" 를 말할 구조가 없다).
