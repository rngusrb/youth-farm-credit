# 지침 코퍼스

이 디렉토리는 비어 있는 채로 배포된다. **실제 시행지침 원문을 여기에 넣어야
`/api/v1/regulation/ask` 가 답을 낸다.** 근거 없이 답을 만들어내지 않도록,
코퍼스가 비면 API 는 항상 `"확인된 근거를 찾지 못했습니다"` 를 반환한다.

## 넣는 방법

### 1) JSONL — 권장 (수작업 정제본)

표가 많은 HWP/HWPX 를 자동 파싱하면 셀이 깨진다. 명세 §6 이 허용한 대로
조항 단위로 정제한 JSONL 을 넣는다. 파일명은 자유, 확장자는 `.jsonl`.

```jsonl
{"doc_title":"2026 청년후계농 영농정착지원사업 시행지침","doc_year":2026,"section_path":"III-2-나","region":null,"source_url":"https://...","text":"조항 원문을 그대로. 요약하지 말 것."}
```

필수 필드: `doc_title`, `section_path`, `text`. 선택: `doc_year`, `region`, `source_url`, `chunk_id`.

### 2) 평문 — 자동 조항 분할

`.txt` / `.md` 파일을 넣으면 `제12조`, `III-2-나`, `3.`, `가.` 같은 헤딩을
경로로 누적해 자동 분할한다. 첫 줄에 머리말을 두면 메타데이터가 된다.

```
# 2026 청년후계농 영농정착지원사업 시행지침 | 2026 | https://...
```

## 색인 생성

```bash
python -m rag.ingest
```

`index.jsonl` 이 만들어진다. 서버는 이 파일만 읽는다.

## 대상 문서 (명세 §6)

- 청년후계농 영농정착지원사업 시행지침
- 후계농업경영인 육성자금 규정
- 농업자금이차보전 사업시행지침
